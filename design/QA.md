# UI 原型验证记录

日期：2026-09-16。验证对象仅为浏览器交互原型，不代表真实采集能力。

## 已验证

- 录音开始、停止、录制中改名；模式在录制中锁定。
- 两路声音独立开关；全部关闭时不能开始。录制中保留至少一路声音。
- 快捷键 Option+R 收起 / 呼出面板，收起时录制状态和计时继续。
- 区域拖动框选、窗口选择、全屏选择；确认后开始录屏，Escape 取消。
- 录音保存一份演示音频，录屏保存视频和独立音频。
- 历史详情中的改名会更新两个关联文件名，支持显示路径和演示播放。
- 修改存储位置后下次录制采用新路径，当前录制仍使用原位置。
- 1280×920 和 390×844 下人工看图；窄窗口无横向溢出，主按钮保持可见。
- 浏览器错误日志为空；JavaScript 语法检查及 git diff --check 通过。

## 检查中修复

- 保存提示层拦截历史条目点击：提示层改为不接收指针事件。
- 选区确认事件冒泡触发外部点击，导致刚打开的面板被关闭：外部点击关闭逻辑排除选区表面。
- 录制计时使菜单栏图标位置变化：面板尖角动态跟随菜单栏入口。
- 小字偏淡：加大并加深声音状态、文件名、保存路径与最近记录的文本。

## 明确的原型边界

- 电平、时间预设、文件大小和历史素材包含模拟数据。
- 播放演示只展示播放器交互和进度，不播放实际会议音视频。
- 未调用录音、屏幕采集、原生文件夹选择器、Finder 或全局快捷键 API。
- 原型快捷键仅在页面有焦点时生效；路径设置只保存在此原型的浏览器存储中。
- 显示真实声音电平、处理系统权限、长时间录制恢复等应在 macOS 应用实现阶段验证。
