# Scriber 使用说明

Scriber 常驻 macOS 菜单栏，用于随手录下电脑声音、麦克风和屏幕，得到本地 M4A / MP4 文件。当前面向本机 Apple Silicon、macOS 26+ 使用。

## 下载和安装

从 [GitHub Release](https://github.com/luyao618/dayscribe/releases/tag/v0.1.0) 下载 `Scriber-0.1.0-macOS-arm64.dmg`，打开后将 Scriber.app 拖进 Applications（应用程序）。也可下载 ZIP，解压后把应用移到「应用程序」。不要下载用于开发的 Source code 压缩包。安装使用无需 Xcode 或终端命令。

当前预览版尚未 Apple 公证。若首次打开被系统拦截，请先尝试打开 Scriber，再到 **系统设置 → 隐私与安全性**，为 Scriber 点击 **仍要打开** 并确认；只对来自本仓库且你信任的下载这样操作，无需关闭 Gatekeeper。升级前先退出 Scriber，再替换应用；从以前的本地开发包切换到发布包后，macOS 可能要求重新授权录制权限。

## 启动和首次权限

从「应用程序」打开 Scriber。点击菜单栏的波形图标，或按默认快捷键 **⌥R**，打开录制面板。收起面板、切换应用会继续录制。

首次录制时，按系统提示允许 Scriber 使用「屏幕与系统音频录制」；开启麦克风时还需要「麦克风」权限。可以在 **系统设置 → 隐私与安全性** 中检查这两项。当前采集引擎仅录麦克风时也需要屏幕与系统音频录制权限。若系统要求重启应用，先退出 Scriber 再打开。

## 界面语言

Scriber 在启动时读取 macOS 的首选语言：英文（包括美式、英式等地区变体）显示英文，其余默认简体中文。若只想改变 Scriber，可在 **系统设置 → 通用 → 语言与地区 → 应用程序** 中添加 Scriber，选择中文或英文；退出并重新打开应用后生效。应用没有额外的语言开关。

切换语言不会修改已有文件名、录制记录和保存目录。新录制的默认文件名使用当前界面语言；之前保存的警告保留当时的原文。系统选择器和系统错误由 macOS 提供。下文使用中文按钮名称，演示视频中的实拍界面也采用中文。

## 录音

1. 选择「录音」。
2. 按需开启「电脑声音」和「麦克风」，至少保留一路。
3. 点「开始录音」。检查时长增长，以及所选声音来源的实际电平和状态。
4. 点「停止并保存」，等「正在保存」结束。

最终得到一个 **M4A**，其中混合了录制时开启的声音来源。电脑声音包含系统正在播放的声音；麦克风使用系统默认输入设备。

「等待声音」表示当前收到的声音很轻或静音；「等待声音数据」「正在重连」「采集中断」是不同状态，不能据此假定内容已经录到。录制时可开关声音来源，最后一路不能直接关闭。选择的来源会记住，下次启动沿用。

## 录屏

1. 选择「录屏」，确认声音来源。
2. 在范围行选择「自选区域」「单个窗口」或「整块屏幕」。
3. 点「选择范围并录屏」。区域模式拖动框选后按回车或「开始录屏」；窗口／屏幕模式在系统选择界面中确认。Esc 取消。
4. 录完点「停止并保存」。

录音／录屏模式及范围类型会记住，下次启动沿用；具体窗口、屏幕或区域仍需每次确认。

最终得到同名的 **MP4 视频和 M4A 音频**，放在同一个目录。MP4 自带声音，M4A 可以单独交给其他工具处理。选择窗口只限定画面，电脑声音仍包含系统播放的声音。

## 文件名、目录和历史

点击计时器下方的文件名或铅笔，输入名称后按回车或勾号确认；Esc 或收起面板取消未确认的编辑。可在开始前、录制中及保存后修改。保存后的改名会一起处理该次录屏的已保存文件，重名自动编号，避免覆盖。

默认目录：

- 录音：`~/Movies/Scriber/录音`
- 录屏：`~/Movies/Scriber/录屏`

点击面板中的目录行，或打开 **设置 → 保存位置设置**，可分别修改两种目录。录制中更改目录从下一次生效，本次继续保存到开始时的位置。

点击历史图标或「查看全部」可搜索录制、进入详情播放、切换视频／音频预览和改名。文件夹按钮在 Finder 中定位文件。每次录屏的 MP4 和 M4A 归在同一条记录中。收起面板会暂停预览，不影响正在进行的录制。

在 **设置 → 呼出快捷键** 中可修改或关闭快捷键；无法注册新组合时会保留原设置。**设置 → 退出 Scriber** 会等待当前录制保存或恢复操作收尾后退出。

## 中断或保存警告

「已保存 · 请查看提示」表示文件已保存，但录制期间或收尾时有需要检查的信息；「部分文件已保存」表示只有部分输出可用。先看具体提示，再到历史中检查和播放已保存的文件。已保存成员仍可改名，警告记录会保留。

设备失效时，Scriber 会有限重试并保留仍能工作的声音来源；不会把你关闭的麦克风自动打开。全部来源无法恢复时会结束录制。磁盘空间不足时也会停止并尝试收尾，保留可用内容。

异常退出后重新打开 Scriber，它会检查未完成录制并尝试恢复已有内容。也可使用 **设置 → 检查未完成录制**。恢复不会补出未录到的声音或画面，最后尚未完整写入的一段可能缺失；原始数据会保留。

录制期间已加入防闲置睡眠保护，录屏也防闲置熄屏。主动睡眠时会尝试停止和保存，唤醒后需手动开始新录制。实际睡眠、合盖、锁屏转换和 USB／蓝牙切换仍有待完成的验收，见下方记录。

## 当前验收状态

8 小时录音、2 小时录屏是验收基准，软件不设置对应的时长上限。原生操作与两项真实长测的文件复核已完成；八小时录音仍保留麦克风恢复警告，未证明全程声音连续。耳机物理切换、麦克风连续性，以及锁屏／睡眠／合盖由用户后续自行验收，发现问题再提 bug，不阻塞已交付的 v0.1。最新结论见 [ACCEPTANCE.md](ACCEPTANCE.md)，详细证据见 [VALIDATION.md](VALIDATION.md)，完整范围见 [SPEC.md](../SPEC.md)。

## 从源代码构建

需要 Xcode 26，在项目根目录运行：

```sh
./scripts/build-app.sh release
open build/Scriber.app
```

构建前先退出 Scriber，脚本会拒绝覆盖正在运行的应用。脚本优先使用本机唯一的 Apple Development 签名身份；没有或无法唯一确定时使用本地 ad-hoc 签名。应用运行不依赖 ffmpeg、Python 或云服务；这些只用于开发验收。更多开发命令见 [README.md](../README.md)。
