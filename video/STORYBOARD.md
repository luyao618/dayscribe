# Scriber · 留下声音，也留下画面

目标：60 秒内让第一次见到 Scriber 的人理解用途、完成一次录制，并知道如何找到本地文件。当前版本采用英文旁白、英文画面说明与中英双语字幕，配原创轻音乐。逐句文案和时序见 narration-en.json；下表保留原始分镜的中文说明。实拍部分使用应用当前的中文界面。

视觉沿用原生面板：Pearl #F4F5F8、Paper #FFFFFF、Ink #262B38、Iris #7067CF、Jade #399980、Record #DA666A。中文使用系统 PingFang SC，品牌用系统圆角风格，时间和文件扩展名用 SF Mono。1920×1080、30 fps。

主体采用左侧大字说明、右侧原生面板；文件输出段改为横向两份文件，体现录屏的一次录制、两个输出。紫色与绿色声音轨迹汇聚为本地文件，是整片的视觉线索。不会复刻参考项目品牌或使用其素材。

| 时间 | 信息 | 画面 |
|---|---|---|
| 0–6 秒 | 会议、通话、视频。值得留下，就录下来。 | 原创声音轨迹汇聚，Scriber 品牌揭示 |
| 6–12 秒 | 菜单栏里，随时开始。点击图标，或按 ⌥R。 | 原生待机面板，呼出与开始按钮引导 |
| 12–22 秒 | 电脑声音、麦克风，分别开关。点「开始录音」。 | 原生录音与实时电平；真实操作演示 |
| 22–29 秒 | 正在录什么，一眼就知道。时长、收音状态，录制中也能改名。 | 原生文件名编辑与录制状态 |
| 29–40 秒 | 画面也想留？区域、窗口、整屏。 | 原生录屏范围选择与录屏状态，辅以范围示意 |
| 40–48 秒 | 一次录屏，两份文件。带声音的 MP4 + 独立 M4A。 | 两个文件从同一次录制出现；只录音则输出一个 M4A |
| 48–55 秒 | 存在哪里，你来定。历史里播放、改名、定位。 | 原生目录设置和历史详情 |
| 55–60 秒 | 录下来，接着用。Scriber · macOS 菜单栏录音与录屏。 | 回看／分享／交给你的 Agent；品牌收束 |

演示使用隔离目录中的示例名称及无敏感内容素材。实际原生画面为剪辑素材，说明动画不表示产品新增界面；Agent 总结由其他工具完成，Scriber 不内置转录或 AI。首次使用需授予系统录音／录屏权限。长测与硬件限制仍见 docs/ACCEPTANCE.md。
